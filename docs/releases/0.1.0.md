# Cota 0.1.0

Cota is a hub you run yourself for the AI coding subscriptions and API plans you hold. Every machine you work on sends Claude Code, Codex, OpenCode and Pi through it, and the hub forwards each client's own login, bills each project to the subscription you chose, keeps every request and conversation in a request log you can search, and shows every plan's quota windows in one dashboard.

This is its first release.

## What it holds

- **The hub image**, `ghcr.io/limineol/cota-hub:0.1.0`, for `linux/amd64` and `linux/arm64`: the hub and its dashboard, which run beside ClickHouse by the Compose file. Its digest is below.
- **`cota`**, the program each machine runs, for macOS on arm64 and x64, Linux on x64 and arm64, and Windows on x64: `cota-darwin-arm64`, `cota-darwin-x64`, `cota-linux-x64`, `cota-linux-arm64` and `cota-windows-x64.exe`, each started on its own system before it was published, with their SHA-256 in `SHA256SUMS`.
- **`compose.yaml` and `cota.toml`**, the deployment's Compose file and configuration as they are at this release (the repository's `deploy/compose.yaml` and `deploy/cota.toml`), whose SHA-256 are in `SHA256SUMS` too.
- Each of these has GitHub's build provenance, made by the workflow that built or published it.

What the hub and `cota` do is the README's "What it does", at this release.

## What it does not hold

- Sharing requests across several subscriptions of one provider (load balancing), and Codex over a WebSocket: through the hub, Codex uses HTTP.
- `cota` signed for macOS or Windows. No binary is signed for Cota with a developer's identity, so a system's own checks may warn about or refuse a copy a browser downloaded.
- A way for `cota` to update itself, and a package of it for npm or any other package manager.

## Upgrading

None: this is the first release.

- **The hub store**: there is no earlier release's store to add a step to. The hub makes its store at its first start.
- **ClickHouse's image**: no earlier release named one. This release's is `clickhouse/clickhouse-server:26.8.36.3`.

## Installing

Follow [`docs/install.md` as it is at this release](https://github.com/limineol/cota/blob/v0.1.0/docs/install.md), the install prompt, written for a coding agent and plain steps you can follow yourself. At this release it builds the hub image and `cota` from a checkout of the repository, with Docker, Git and Bun: it does not use the downloads above yet.
